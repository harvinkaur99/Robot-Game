# Robot Game

A Python project exploring core programming concepts — functions, loops, and 
object-oriented programming — through a simple robot simulation built in Jupyter Notebook.

## Concepts covered
- Functions: how they're defined and why they're used (avoiding repeated code, 
  keeping programs clean and reusable)
- Loops and conditional logic
- Object-oriented programming (robot movement and task logic)

## Example: placing bricks
One of the core functions, `place_bricks`, generates random row/column positions 
on a grid and places a brick if that position is empty:

- Runs until the required number of bricks is placed
- Generates random row and column positions
- Checks if the position is empty (".")
- If empty, places a brick ("B") in that position
